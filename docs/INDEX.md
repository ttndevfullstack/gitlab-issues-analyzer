## 📌 Key Concepts

Before diving in, understand:
- **WWWH-TR Framework**: Analysis structure (Why, What, Who, How, Test, Reflect)
- **Stateless Design**: No database, minimal state
- **Webhook vs Polling**: Two modes for issue detection
- **Free Tier Strategy**: Designed for zero cost operation
